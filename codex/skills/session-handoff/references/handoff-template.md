# 交接摘要结构

按实际信息填充以下结构，不相关的部分可省略；未知事实明确标记，不保留尖括号占位符。默认使用段落和列表。用户要求表格原始 Markdown 时，用代码块输出表格。

```markdown
# <任务名称>：交接

- 更新时间：<日期、时间、时区>
- 源任务：<可获取的任务 ID/链接，否则注明未获取>
- 工作位置：<本地主机/远程机器和绝对路径>

## 目标与约束
- 当前目标、完成标准、范围。
- 最新修正、仍有效的明确授权及限制；待批准事项单列。

## 当前状态
- 已完成：<成果和位置>
- 已验证：<验证对象/版本、方法、结果、时间、证据位置>
- 未验证：<哪些部分尚未运行或核实及原因>
- 进行中或阻塞：<确切事项、原因、解除条件>

## 关键决策与已排除方案
- <决策及原因、依据；明确已采纳还是建议>
- <失败尝试、失败条件和证据，避免重复尝试>
- <被取代的旧结论及替代结论，仅保留影响后续工作者>

## 优化与工程验证结果
- <优化编号和改动；有效/无明显收益/退化/不确定/未验证；保留/回滚/待决定>
- <基线及对比条件；指标和单位：基线值 → 优化后值；绝对变化、相对收益及波动>
- <正确性、精度、稳定性等实际验证结果与未覆盖项；副作用>
- 完整记录：<优化记录路径，包含所有已尝试项及日志证据；组合收益注明实测基线>

## 代码和运行现场
- <仓库绝对路径、分支、HEAD、未提交改动及归属>
- <机器、连接方式、工作目录、进程/job/tmux、端口、日志>
- <每项易变化信息的最后观察时间；当前已核实或未刷新>

## 下一步
1. <第一步：机器、目录、操作、预期结果>
2. <后续关键动作和依赖>
- 待用户决定：<仅列阻碍推进的实质选择；没有则省略>

## 资料索引
- <路径或链接>：<内容、用途、必要时版本/时间；远程路径标明机器>
- <详细实验/日志/历史快照路径>：<何时需要读取>
```

对于无代码的分析任务，运行现场可换成数据来源、筛选范围、单位、统计口径和输出路径。多机器、多实验只在摘要保留仍在进行或影响决策的条目，完整记录放详细资料。
