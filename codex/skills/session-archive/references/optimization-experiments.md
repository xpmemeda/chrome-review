# 推理优化实验归档

仅当会话涉及推理优化、性能调优或相关工程实验时使用本规范。它补充会话归档，不取代归档中的目标、当前状态、关键决策、运行现场和下一步。

## 记录目标

归档范围内每个优化尝试都应有去处，包括有效、无明显收益、退化、结论不确定、未验证、失败和已经回滚的尝试。不要只保留最佳方案，也不要把多次实验压缩成一个无法追溯的最终数字。

区分两类对象：

- `OPT-<编号>`：一个明确的优化改动或假设，例如更换 attention 实现、调整量化策略或修改调度逻辑。
- `EXP-<编号>`：一次有确定版本、环境、负载和结果的实验运行。一个 OPT 可以有多次 EXP；一个 EXP 也可以测试多个 OPT 的组合。

优先沿用已有编号。没有编号时，在当前归档中分配简短稳定编号，之后追加记录不得复用给其他事项。归档的是已有事实，不得为了凑齐记录而重跑测试。

## 在归档中的组织

保持归档主线简洁，并分三层保存实验信息：

1. **累计优化索引**：最新归档记录列出所有仍影响当前实现或后续判断的 OPT，包括为了避免重试而必须保留的无效/失败项。每项给出当前结论、最关键的可比数据和去向。
2. **本轮实验明细**：新建归档时记录当前可见范围内的所有已知实验；追加归档时完整记录自上一条归档以来新增、复测或结论变化的 EXP。
3. **原始证据索引**：保存日志、报告、配置、命令或结果文件的路径及所属机器，不把大段原始日志复制进归档。

旧归档记录保持不变。后续发现旧数据或结论有误时，追加更正记录，引用原 OPT/EXP 编号，写清替代关系和更正依据，不静默改写历史。

## OPT 优化项字段

每个优化项尽量记录以下已知字段；缺失项标未知，不推测：

- **编号与名称**：稳定的 OPT 编号和简短名称。
- **假设**：要解决的瓶颈、预期影响的指标和适用边界。
- **具体改动**：代码文件/符号、commit 或 patch，配置项、启动参数、环境变量、模型工件；涉及多个仓库时分别写明版本。敏感值只保留脱敏说明。
- **实施时间**：实际改动时间或已知精度的时间范围，不用归档时间代替。
- **关联实验**：验证该优化的 EXP 编号；区分单项验证和组合验证。
- **当前结论**：有效、无明显收益、退化、结论不确定或未验证，并注明成立条件。
- **最终去向**：保留、回滚、待复测、被取代或仅供参考；给出决定时间和依据。

“预计能提升”不是实验结果。没有可比数据时写收益未知或未验证。

## EXP 实验字段

每次实验运行记录：

- **编号、目的和时间**：EXP 编号、要回答的问题、运行起止时间或完成时间及时区。
- **测试对象**：关联 OPT，单项还是组合；候选版本、commit、配置和服务端口。
- **基线**：基线 EXP/版本/配置，或明确说明无基线。复用旧基线时注明其时间和环境是否仍可比。
- **环境**：机器、GPU 型号与卡数、软件版本、模型与精度、并行与量化配置，以及会显著影响结果的运行参数。
- **负载**：数据集或请求来源、输入/输出或图像尺寸、batch、并发、请求数、预热、重复次数和统计口径。只记录实际使用的条件。
- **实测数据**：指标名称、单位、方向、基线值、候选值、绝对变化、相对变化及已知波动。可保留原始样本时保留；数据较多时保存样本数和均值/中位数/分位数等实际统计量，并索引原始结果。
- **工程验证**：正确性、精度、质量、稳定性、显存、兼容性等实际检查结果和未覆盖项。性能提升不等于工程验证通过。
- **结论与证据**：有效性结论、限制、副作用、日志/报告/配置路径，以及保留、回滚或复测决定。

指标按实际任务选择，例如 TTFT、TPOT/TBT、端到端延迟、吞吐、QPS、显存或生成质量；不要为了模板补造未测指标。延迟类通常越低越好，吞吐类通常越高越好，归档中要明确方向。

相对收益使用与指标方向一致的公式：

- 越低越好：`(基线值 - 候选值) / 基线值`。
- 越高越好：`(候选值 - 基线值) / 基线值`。

基线为零、缺失或不可比时不计算百分比。组合实验的收益只能写相对明确基线的实测结果，不能相加各 OPT 的单项收益，也不能把组合收益归因给未经单独验证的某一项。

## 判断与完整性

- 条件不可比、样本不足、结果落在已知波动内或正确性未通过时，不宣称确定收益，标记“结论不确定”并说明原因。
- 同一优化的多次复测分别保留 EXP 记录，不用最后一次覆盖前面的结果；在 OPT 当前结论中解释为何采纳某次或综合哪些结果。
- 失败、崩溃、OOM、超时和无有效输出也是实验结果，记录失败阶段、错误证据和可确认的边界，但不虚构性能数值。
- 若完整实验历史另有维护文件，归档仍需保存累计索引、本轮关键明细和结论，并链接完整记录；不能只写一个路径而不说明当前判断。
